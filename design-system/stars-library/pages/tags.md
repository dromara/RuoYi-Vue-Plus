# Page Override: 标签管理 `/tags`

## PC

- 页面标题 section-title「标签」
- 右上「新建标签」primary sm
- **表格**：极简，无 zebra 冷色
  - 列：色点 · 名称 · 引用数 · 操作
  - 分隔线 `--border-soft`
- 编辑：inline 或侧滑（非 modal 堆叠）

## H5（精简）

- 列表卡片：色点 + 名 + 次数
- 仅：新建、删除（无重命名 — 或长按编辑 P1）
- 不用 PC 表格

## 色点

- 预设暖色盘：`#1B365D` `#504e49` `#6b5a3d` `#3d5a4a` `#6b3d3d`
- 禁止 neon 色

## 删除

- 确认：「删除后将从 N 个仓库移除此标签」
